retriever puppy mid-leap in an explosion of Holi powder colors — magenta,
turquoise, yellow and orange against a blue sky. Pure joy, frozen mid-air.

## How it works

`main.py` (Python 3.13 standard library only) copies `entry.png` to
`/output/entry.png`. No network, no randomness, no clock — every run writes
the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Facts

- `entry.png`: 1024x1024 PNG, 401,270 bytes (limit 1 MiB, 1024x1024)
- Two local runs produce byte-identical output
